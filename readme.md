# Mental Health Risk Prediction

An end-to-end Machine Learning project that analyzes social media usage and related lifestyle factors to predict a student's mental health score.

## 📌 Project Overview

Mental health can be influenced by multiple factors, including social media usage, sleep patterns, academic pressure, relationships, and daily habits.

This project uses Machine Learning to analyze these factors and predict a mental health score based on the provided user inputs.

The project includes:

* Data preprocessing and analysis
* Exploratory Data Analysis (EDA)
* Machine Learning model training
* Model evaluation
* Model serialization using Pickle
* Web-based prediction interface

## 🎯 Problem Statement

Students' mental health can be affected by factors such as excessive social media usage, lack of sleep, academic stress, and lifestyle habits.

The goal of this project is to build a Machine Learning model that can analyze these factors and generate a predicted mental health score.

> **Note:** This project is created for educational and research purposes only. It is not a medical diagnostic tool and should not be used as a substitute for professional mental health advice.

## 📊 Dataset

The project uses the **Student Social Media and Mental Health Impact** dataset.

The dataset contains information related to students and factors that may affect their mental well-being, including social media usage and other lifestyle-related features.

## 🤖 Machine Learning Model

The Machine Learning workflow includes:

1. Loading the dataset
2. Understanding the data
3. Handling missing values
4. Data preprocessing
5. Feature preparation
6. Splitting the dataset into training and testing data
7. Training the Machine Learning model
8. Evaluating model performance
9. Saving the trained model as `Mental_Health_Model.pkl`

## 🌐 Web Application

The application provides an interface where users can enter the required information.

The input data is processed by the backend, passed to the trained Machine Learning model, and the predicted mental health score is returned to the user.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/mental-health-risk-prediction.git
```

### 2. Move to the Project Directory

```bash
cd mental-health-risk-prediction
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python main.py
```
